AUTOMAT - WATCHDOG AND AUTORUN
==============================

What the watchdog does
----------------------
The watchdog is a small hidden monitor for the production build of Automat.
It can keep running, but it restarts Automat only when Autorun is enabled in the application settings.

When Autorun is disabled, the watchdog does not start anything.


How to run Automat with the watchdog
------------------------------------
1. Start the production build with:
   start.bat

2. If Automat is not installed yet, start.bat runs the installer first.

3. start.bat starts:
   - the Automat server hidden,
   - the watchdog hidden.

4. In the application, click the settings gear in the top bar.

5. Enable Autorun.

From that moment, when the server is closed or crashes, the watchdog starts Automat again.


How to start the watchdog automatically after Windows login
-----------------------------------------------------------
The easiest way:

1. In the production build folder, run:
   pridat_watchdog_po_prihlaseni.bat

2. The script creates a shortcut named:
   Automat Watchdog.lnk

   in the current Windows user's Startup folder.

3. After the next Windows login, the watchdog starts hidden.

4. The watchdog checks the Automat database:
   - if Autorun is disabled, it does nothing,
   - if Autorun is enabled and Automat is not running, it starts Automat.


How to remove watchdog autostart
--------------------------------
Run:
odebrat_watchdog_po_prihlaseni.bat

This removes the shortcut from the Startup folder.


Manual Windows setup
--------------------
If you want to do it manually:

1. Press Win + R.
2. Enter:
   shell:startup
3. In the opened folder, create a shortcut to:
   watchdog_hidden.vbs

Using the prepared script `pridat_watchdog_po_prihlaseni.bat` is easier.


Important behavior
------------------
- The watchdog is included only in the production build.
- The development version does not start it.
- The watchdog does not run workflows by itself.
- The watchdog only restarts the Automat server.
- Autorun inside Automat then selects the first saved site, optionally performs login, and starts the first workflow in an infinite loop.
- When Autorun is disabled, the watchdog may stay running, but it will not restart Automat.


Logs
----
The watchdog writes simple logs here:
data\watchdog.log
data\watchdog-start.log

The Automat server writes its log here:
datautomat-server.log
